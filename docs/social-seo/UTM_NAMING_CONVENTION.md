# Convención UTM

Usar minúsculas, guiones bajos y valores controlados. No incluir email, teléfono, nombre de usuario privado ni matrícula.

- `utm_source`: `instagram`, `tiktok`, `youtube`, `pinterest`, `facebook`, `linkedin`, `google_business`
- `utm_medium`: `organic_social`, `video`, `short`, `pin`, `profile`, `post`, `story`
- `utm_campaign`: `gran_canaria`, `tenerife`, `lanzarote`, `fuerteventura`, `owner_acquisition`, `campervan_hire`, `motorhome`, `vanlife`

Ejemplo: `/alquiler-camper/gran-canaria?utm_source=instagram&utm_medium=post&utm_campaign=gran_canaria`.

La URL de destino debe ser la landing, guía o ficha concreta; no redirigir todo a la home.
