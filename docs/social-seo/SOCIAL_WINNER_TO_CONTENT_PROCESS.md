# Proceso de contenido ganador

1. Detectar vídeo o pin con intención clara.
2. Revisar comentarios y términos buscados.
3. Comprobar si existe landing o guía.
4. Reforzar la URL existente si responde a la intención.
5. Crear URL nueva solo si la intención es realmente distinta.
6. Revisar canonical, enlaces internos y riesgo de canibalización.
7. Medir visitas, fichas vistas, búsquedas y reservas, no solo seguidores.
